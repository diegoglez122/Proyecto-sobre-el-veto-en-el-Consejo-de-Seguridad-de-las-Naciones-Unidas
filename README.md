# Proyecto sobre el veto en el Consejo de Seguridad de las Naciones Unidas

Análisis interactivo del uso del derecho de veto por parte de los cinco miembros permanentes del Consejo de Seguridad de la ONU (1946 - hoy).

## 🚀 Demo en vivo
Puedes ver el dashboard funcionando aquí: [veto-onu.onrender.com](https://veto-onu.onrender.com)

## 🛠️ Tecnologías
* Python
* Streamlit
* Pandas
* Plotly

## 📊 Funcionalidades
- Filtros por país y década.
- Visualización de vetos acumulados en el tiempo.
- Comparador cara a cara entre países.
- Minijuego de trivia.
